# Quick Bunny — Level 3

A sprite-based browser game in which the bunny navigates a scrolling-style playfield, avoids generated snakes, and tries to reach a carrot.

## Controls

Use the arrow keys to move. Contact with a snake resets the bunny to its starting position; touching the carrot displays the win message.

## Stack

- HTML5
- JavaScript with p5.js and p5.play
- CSS plus local artwork in `CSS/`, `lib/`, and `images/`

## Run

Open `index.html` in a browser. Keep the image assets and support folders at their existing paths because `sketch.js` loads artwork from `images/`.
